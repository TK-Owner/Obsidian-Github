# Inbox整理

## 目的
00_Inbox/Inbox.md と LINE/ 配下の未処理ノートを読み、適切な場所に振り分ける。

## 手順
1. `00_Inbox/Inbox.md` の未チェック項目と、`LINE/` 配下で未処理のノートを列挙する
2. 各項目を「知識（10_Knowledge）／手順（20_Skills）／案件（30_Projects）／捨てる」に分類し、振り分け案を提示する
3. 承認されたら、該当ノートに日付見出し付きで追記する（新規テーマは新ノート＋索引にリンク追加）
4. Inbox の項目にチェックを付け、処理済みの LINE ノートは末尾に `processed: YYYY-MM-DD` を追記する

## 注意
- 判断に迷う項目は勝手に振り分けず、案として提示して確認を取る

## 2026-09-20
週次 Skill 収穫より。9/16〜9/19 のセッションログで 4 日連続「LINE 受信箱の要約取り込み」を同じ流れで実施していたため、手順 2 の「読む」部分を具体化する。

### URL の本文の取り方（アプリ内ブラウザ）
- LINE ノートは URL 1 行のみのことがほとんど。分類する前に必ず本文を取りに行く
- Instagram: ログイン必須。ページを開いたら find「さらに表示」→ クリック → get_page_text でキャプション全文。先頭の投稿が目的のリール
- X: navigate → get_page_text。「記事」形式は投稿カード（記事タイトル）を find → left_click → get_page_text で全文が読める
- YouTube ショート: navigate → 2 秒待ち → get_page_text でタイトル・チャンネル・説明が取れる
- Facebook の share リンク: 本文が出ない。「本文取得不可」として記録し processed のみ付ける
- 広告トラッキング用と思われる外部リンク（例: discover-news.tokyo）は開かず processed のみ

### 件数が多いとき
- 30 件超はサブエージェントに読ませる
- 90 件超は preview_start で別タブを開き、X 用と Instagram 用にサブエージェントを分けて並行させる（93 件で 15 分程度）

### 分類・記録の決め事（ユーザー決定）
- 見送り候補も「思考の整理」として Vault に残す。他に収まらないものは `10_Knowledge/暮らし/気になったものメモ`
- キャプションに中身が無い投稿も「保存した事実」として 1 行で残す（未確認と明記）
- AI 美女系は成人向けではなく、デジタルコンテンツ販売のヒントとして `コンテンツ販売/AI美女・キャラ運用` に入れる
- 車系ノートはまだ作らない（気になったものメモに置く）
- 購入候補・案件になりそうなものは判断せず Inbox.md に「判断保留」として追加する
- 作品名などが検索でも特定できないときは未確定のまま記録する

### 注意（追加）
- LINE のトーク履歴まとめに API トークンなどの機密情報が含まれていたら、Vault に転記せず、再発行と該当行の削除をユーザーに依頼する
- 処理後は Home.md「最近の更新」に「日付 LINE 受信箱の整理（N 件 → 作成・追記したノート）」を 1 行足す
