# Inbox整理

## 目的
00_Inbox/Inbox.md と LINE/ 配下の未処理ノートを読み、適切な場所に振り分ける。

## 手順
1. `00_Inbox/Inbox.md` の未チェック項目と、`LINE/` 配下で未処理のノートを列挙する
2. 各項目を「知識（10_Knowledge）／手順（20_Skills）／案件（30_Projects）／捨てる」に分類し、振り分け案を提示する
3. 承認されたら、該当ノートに日付見出し付きで追記する（新規テーマは新ノート＋索引にリンク追加）
4. Inbox の項目にチェックを付け、処理済みの LINE ノートは末尾に `processed: YYYY-MM-DD` を追記する

## 注意
- 判断に迷う項目は勝手に振り分けず、案として提示して確認を取る
