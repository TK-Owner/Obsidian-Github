# Vaultへの記録

## 目的
会話で得た結論・調査結果・決定事項を、後から探せる形で Vault に残す。

## 手順
1. 記録する内容のテーマを特定し、10_Knowledge の既存ノートを探す（索引 Knowledge.md を参照）
2. 該当ノートがあれば末尾に `## YYYY-MM-DD` 見出しを付けて追記。なければ新規作成し、索引にリンクを追加
3. 決定事項・期限は 30_Projects の該当案件ノートにも追記
4. frontmatter の `updated` を更新し、Home.md の「最近の更新」に1行足す

## 書式
- 結論を先に、根拠・経緯は箇条書きで短く
- 数値や外部情報は出典（URL・日付）を残す
- 機密情報は書かない

## 2026-09-20
週次 Skill 収穫より。9/16 以降の新規ノート作成（10 件超）で定着している書式を補足する。
- 索引（Knowledge.md）への追加は `- [[10_Knowledge/<分類>/<ノート名>|<ノート名>]]（一言の補足）` の形で該当分類の末尾に足す。分類が無ければ `## <分類>` を新設
- Home.md「最近の更新」は `- YYYY-MM-DD 作業名（件数 → 新規／追記したノート名）` の 1 行。同じ日に複数回作業したら行を分ける
- 同じノートに同日 2 回目以降追記するときは `## YYYY-MM-DD（追加分）` のように括弧で区別する
- SNS で拾った情報は「要約と URL のみ」を残し、投稿本文の転記はしない。価格・反応数は取得日時を添える
