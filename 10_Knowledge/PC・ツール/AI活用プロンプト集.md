## 2026-09-16

### 回答の信頼性を上げる（推測を止める）
出典: Threads @kurosaki7606（2026-09-15 保存）
- 推測禁止: 分からないことは推測で埋めず「分からない」と言わせる
- 事実と推測の分離: 確認できる事実と推測を分けて答えさせる
- 根拠チェック: 重要な主張には根拠を付け、無ければその旨を明記させる
- 反証モード: 回答が間違っている前提で矛盾を検証してから最終回答を出させる
- 確信度の明示: 自信のない箇所を断定させない
- 使いどころ: 数字・契約・制度が絡む質問。会話の最初に貼っておくと効き続ける

### 回答の質を上げる（一発目を完成品にしない）
出典: Threads @pikorun_ai（2026-09-15 保存）
- 前提破壊チェック: 質問側の前提の誤り・思い込みを先に確認させる
- 不足情報チェック: 回答前に足りない情報を質問させる
- 70点禁止令: 最初の回答を70点と仮定し、足りない要素を洗って改善版だけ出させる
- 反論テスト: 結論が間違っている前提で穴を3つ以上検証させる
- 専門家レビュー / 3案比較 / 抽象語禁止 / 最終監査（依頼条件を1つずつ照合）

### 役割別テンプレ（Claude を仕事の右腕に）
出典: Threads @y__fixer（2026-09-15 保存）
- 壁打ち役（賛成せず弱点3つ→代案1つ）、議事録役（決定／宿題／保留に分ける）、返信下書き役（断る／条件付き／日程のみ の3案）、要約役（読み手を指定し数字は資料内のみ）、資料構成役、チェック役、データ整理役、調べもの役、教える役、自己採点役
- コツ: 先に資料を渡し、最後に自己採点をさせる。まず「賛成しないで」「弱点3つ」の2行から

### Gemini への指示は4要素の順で
出典: Threads @y__fixer（2026-08-22 投稿、2026-09-15 保存）
- ペルソナ（誰として）→ タスク（動詞1つで言い切る）→ コンテキスト（用途・前回の失敗まで）→ 形式（長さ・箇条書き／表・項目）
- 埋まらない欄があるなら自分の中で条件が決まっていないサイン
- Gemini の「回答を再確認」で Google 検索と照合（緑=一致、オレンジ=要確認）

### GPT-6 Astra の使い方 10 選（「質問」ではなく「発注」）
出典: X 記事 @haru_affiliate1「天才の ChatGPT 6 Astra の使い方 10 選」（2026-09-18、@noirinvestor の引用経由）。Astra は 2026-09-03 リリースとのこと
- 本質: Astra は賢さより「エージェント能力」。PC を操作しながら長時間タスクを自律的にこなす力が前モデル比約 2 倍速、途中で目的を忘れにくい。入力 105 万トークン
1. スライドは「コードで」作らせる（WebGL でスクロール切り替え・数字がアニメーションするプレゼン）
2. デザインは Figma ごと操作させる（ターゲット・ブランドカラー・参考 URL を渡して LP を作らせる）
3. 3D・ゲームは Blender / Unreal を操縦させ、遊べる HTML の完成品で受け取る
4. 物理のものづくりの入口に使う（構想図→部品リスト→概算コストの順で、各段階で確認を挟む）
5. すき間作業（フォーム記入、CRM 更新、カレンダー整理）を手順ごと丸ごと渡す。「判断に迷ったら進める前に確認して」を添える
6. 本番前の「下ごしらえ」だけ切り出して渡す（映像なら素材取り込み・色調整・同期）
7. 過去に挫折した案件から試す（実現方法を 3 つ出させて一番現実的な方法で試作）
8. 重いタスクを先に投げて並列で働かせる。「AI の作業待ち時間」をスケジュールから消す
9. 資料は小分けにせず全部渡してから考えさせる
10. 「依頼書」で発注し、最後の 2 割を自分で磨く。テンプレ: 目的／完成物（形式）／条件（制約・参考資料・NG）／確認（どの段階でチェックを挟むか）
- 注意: 事実確認と仕上げは人間の仕事。Plus プランには利用枠があるので重い仕事から使う

### Jev（TypeSafe AI「System One」）まとめ
- 2026-09-15 公開。文章を返さず「判定と確率」だけを返すモデル。3 種の判定: Choice（選択）／Noul（Yes 確率）／Score（採点）。しきい値のルールは人間が設計する（X @yama_threads 引用の OneBiz 記事）
- 料金: 入力 100 万トークン $0.042・出力無料。9/21 にウェイトリスト廃止、console.typesafe.ai から誰でも利用可（@noel_ai_lab の記事に公式投稿の埋め込み）
- Claude Code への導入 3 ルート（@karoukun_ai の記事「Claude Code 用 Jev ツール大全」、@ai_ai_ailover 引用）: ①公式スキル `claude plugin marketplace add typesafe-ai/skills` → `claude plugin install typesafe@typesafe-ai` ②MCP 経由（typesafe-mcp / jev-mcp）③モデルルーター経由。Vercel AI Gateway・Cloudflare Workers AI・LiteLLM・LangChain 対応
- Codex への導入（@MakeAI_CEO の記事）: `npx skills add typesafe-ai/skills --skill typesafe-ai`、環境変数 TYPESAFE_API_KEY、SDK は `pip install typesafe-sdk`。「生成は Codex、意味判断は Jev、計算・分岐はコード」の分担が要る
